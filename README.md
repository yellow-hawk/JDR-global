# JDR Global

Suite d'outils de jeu de rôle pour le MJ et sa table : monde (Atlas), cartes, personnages, avatar 3D, magie (Atelier de tracé), combat, campagne, journal, chronologie…

- Application : [`app/`](app/) — Vite + React + TypeScript, sans serveur. Carte du projet : [`app/CLAUDE.md`](app/CLAUDE.md), mode d'emploi : [`app/LISEZMOI.md`](app/LISEZMOI.md).
- Format de données : [`docs/format-jdr-global.md`](docs/format-jdr-global.md) · journal : [`docs/journal-de-bord.md`](docs/journal-de-bord.md).
- Analyse de départ : [`00 - Analyse et propositions.md`](00%20-%20Analyse%20et%20propositions.md).

```bash
cd app
npm install
npm run dev
```
